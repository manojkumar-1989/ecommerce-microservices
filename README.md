
# E-Commerce Microservices

An E-Commerce application developed using Java 17 and Spring Boot.

## Microservices

1. User Service
2. Product Service
3. Order Service
4. Payment Service

## Technology Stack

- Java 17
- Spring Boot
- Maven
- MySQL
- REST APIs
- Git and GitHub
- Docker

## Project Structure

```text
ecommerce-microservices/
├── user-service/
├── product-service/
├── order-service/
├── payment-service/
├── README.md
└── .gitignore
```

## Development

Each microservice will be developed, tested and maintained independently.
